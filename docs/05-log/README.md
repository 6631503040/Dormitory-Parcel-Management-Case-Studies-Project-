# docs/05-log/

Dated working log — one file per working day.

## File naming

```
{YYYYMMDD}-log.md          e.g. 20260904-log.md
```

Other dated artifacts also land here:

```
{YYYYMMDD}-backlog-audit.md   # output of backlog-auditor / /audit-backlog
{YYYYMMDD}-{topic}.md         # advisor meeting notes, sprint review, decisions
```

## What goes in a daily log

- What was done today (link spec files / backlog IDs touched)
- Decisions made and why
- Action items with owners
- Blockers
- Scope requests raised (also add them to `../01-requirements/backlog.md` parking lot)

Keep it short. This is the audit trail of the project's own work, useful for sprint
reviews and the final report.
